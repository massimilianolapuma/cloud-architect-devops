# Traceability matrix

This page maps regulatory requirements (for example DORA, NIS2, GDPR, health data rules) to the chapter that addresses each one, the control that implements it and the evidence that shows it works. It is a skeleton for now: no rows have been added yet.

To add a row, append one line to the table with the requirement, its source (regulation and article), the chapter that covers it, the control, the evidence, and whether the control was verified live on a local machine.

> This is technical support for compliance work, not legal advice. Check every requirement with your legal and compliance functions.
